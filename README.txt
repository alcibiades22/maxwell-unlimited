MAXWELL UNLIMITED — STATIC SITE

FILES
- index.html: landing page
- research.html: research placeholder
- workshop.html: workshop placeholder
- styles.css: all styling and responsive rules
- diagram.svg: editable geometric illustration

TO PUBLISH
Upload all five website files to the public/root folder of your web host. Keep them together in the same directory.

Common root-folder names include:
- public_html
- www
- htdocs
- site

The home page must remain named index.html.

NOTES
- The site uses IBM Plex Sans and IBM Plex Mono from Google Fonts.
- The page works without JavaScript.
- The diagram is an SVG and can be edited in Figma, Illustrator, Inkscape, or a text editor.
